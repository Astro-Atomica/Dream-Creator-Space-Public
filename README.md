# Dream Creator Space

Public documentation, bug reports, and feature requests for [Dream Creator Space](https://dreamcreatorspace.com/), a 3D planner for creator studios.

Plan a room, place equipment, and check camera framing and focus before moving your setup.

- [Open the site](https://dreamcreatorspace.com/)
- [Read the user guide](docs/user-guide.md)
- [Report a bug](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues/new?template=bug_report.md)
- [Request a feature](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues/new?template=feature_request.md)
- [Browse existing reports](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues)

## About this repository

This repository holds public information about the site and tracks feedback. Application source and deployment are maintained separately. Changes here update documentation and reporting guidance; they do not deploy the application.

## What you can plan

- Room layouts, furniture, cameras, lenses, lighting, and other equipment.
- Camera framing, field of view, and depth of field.
- Multiple camera views and rendering modes for inspecting a shot.
- Equipment groups, ownership, and a bill of materials.
- Power connections and estimated loads.

The planner uses approximations. See the [user guide](docs/user-guide.md#understanding-the-preview) for their practical limits.

## Help improve the site

Search existing issues before opening a report. For bugs, include the app version and build, your browser and operating system, and steps to reproduce the problem. The site's **Settings → Report a bug** link opens a draft with the version and build already filled in.

Issues and attachments are public. Remove private room details, inventory identifiers, credentials, and personal information before sharing screenshots or exported files.

See [CONTRIBUTING.md](CONTRIBUTING.md) for reporting and documentation contributions, and the [triage guide](docs/triage.md) for how reports are managed.

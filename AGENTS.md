# Public repository guidance

This repository contains public documentation and issue templates for Dream Creator Space. Application source and deployment are maintained separately.

- Keep documentation grounded in released behavior; do not present requests or local fixes as live features.
- Preserve compatibility with the app's existing prefilled bug-report URL. Keep blank issues enabled so its title and body can be used.
- Use existing `bug`, `enhancement`, and `documentation` labels for the corresponding work.
- Keep private scene data, personal inventory, credentials, local machine paths, deployment details, and internal reviews out of this repository.
- Check relative documentation links and issue-template front matter before committing.
- Preserve unrelated changes. Do not modify or deploy the application as part of documentation work.

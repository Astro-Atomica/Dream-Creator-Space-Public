# Contributing

This repository accepts public bug reports, feature requests, and documentation improvements for [Dream Creator Space](https://dreamcreatorspace.com/).

## Report a bug

Search [existing issues](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues), including closed reports. If the same problem is already tracked, add any new reproduction details there.

Use the [bug template](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues/new?template=bug_report.md), or the site's **Settings → Report a bug** link. Include:

- A short description and the version/build shown in the app.
- Steps to reproduce, expected behavior, and actual behavior.
- Browser version, operating system, and device details relevant to the problem.
- A screenshot or minimal fictional scene, when it helps reproduce the issue.

Export a backup before trying troubleshooting that resets or clears browser data.

## Request a feature

Use the [feature template](https://github.com/Astro-Atomica/Dream-Creator-Space-Public/issues/new?template=feature_request.md). Explain the workflow or problem, the desired result, and any alternatives you have tried. Keep unrelated requests in separate issues. A request being tracked does not promise a release date.

## Improve documentation

Open a pull request with a focused correction or addition. Describe which page changed and how you checked it against the app. Use relative links between repository documents. Keep user-facing instructions separate from implementation and deployment details.

This repository does not contain the application source. Application fixes are implemented separately; link their public outcome back to the relevant issue when available.

## Sharing information

Reports, comments, and attachments here are public. Remove personal information, private room details, asset tags, credentials, and private URLs before posting. Do not post exploitable security details or credentials in public issues; use GitHub's private vulnerability reporting option if it is available on the repository's Security page.

Keep feedback specific, constructive, and respectful. Maintainers use the [triage guide](docs/triage.md) to organize reports.
